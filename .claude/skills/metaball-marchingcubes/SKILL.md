# MarchingCubes メタボールの破れと融合

three.js の `MarchingCubes` は **0..1 の単位立方体**の中に場 (field) を持ち、
`addBall(x, y, z, strength, subtract)` で球の寄与を足し、`isolation` 以上の
領域の表面を三角形にする。見た目の失敗は 2 種類あり、どちらも**エラーにならず
「少し変な絵」が出る**だけなので、数字で先に押さえてから描く。

## 失敗 1: 場の端で面が平らに切れる (破れ)

場は 0..1 の立方体の外に存在しない。球の表面がその外へ出ると、表面は
**壁で切り落とされたように平らになる**。addBall 自体もグリッド境界で寄与を
打ち切るので、端の近くでは膨らみも歪む。

- 球の表面半径 (場の単位) は `r_iso = sqrt(strength / (isolation + subtract))`。
  場の値は `strength / d² − subtract` で、これが `isolation` になる距離が表面。
- 守る予算: 中心の最大変位 + 揺らぎ + `r_iso` を **0.47 以下** (= 0.5 ± 0.47、
  端から 3% の余白) に収める。軌道半径・ウォブル・上下動・strength の変調 (strength を
  +8% すると r_iso も伸びる) を**全部足した最悪値**で見る。
- 大きく見せたいときは `strength` を上げるのではなく **mesh の `scale` を上げる**。
  場の単位はそのままで世界座標だけ拡大できる。

## 失敗 2: 離れたのに繋がったまま / 近づけたのに融合しない

2 球が「表面同士が触れる」距離にあると、その中点では**それぞれが isolation
ちょうどの値を出す**ので和は 2 × isolation。つまり**名目半径が触れるよりずっと
手前で融合する**。分離させたければ中点の和が isolation を下回る距離が要る:

- 2 球の中点距離 d で `strength / d² − subtract ≤ isolation / 2` ⇒
  `d ≥ sqrt(strength / (subtract + isolation / 2))`。中心間距離はその 2 倍。
  isolation ちょうどでは揺らぎで繋がったり切れたりしてちらつくので、名目値で
  isolation の 85% 以下を目安にする (60 なら 51 以下。実例の 58 は目で見て際どかった)。
- 3 球を正三角形に置くなら、辺の中点に第 3 の球も寄与する (距離 1.5 × 外接半径)。
  外接半径 R に対して辺 = √3 R なので、上の d から R を逆算し、第 3 球の分も足す。
- 逆に「融合させたい」なら中点の和が isolation を十分越える距離まで寄せる。
  融合期の中心付近の値は数百〜数千になるので余裕は大きい。

破れの予算 (失敗 1) と分離の距離 (失敗 2) は**反対方向に引っ張る**: 分離したければ
離したい、離すと端に当たる。両立させるには球を小さく (`strength` を下げ) して
`scale` で見た目を戻すのが定石。今回の実例: strength 3.4 → 1.8、軌道 0.26 → 0.27、
scale 2.0 → 2.6 で、端にも当たらず分離時の中点が 32〜45 (< 60) になった。

## 手順

1. 球の数・isolation・subtract・動きの最大振幅を決めたら、まず予算を計算する:
   ```bash
   python scripts/metaball_budget.py --strength 1.8 --subtract 12 --iso 60 \
       --orbit 0.27 --wobble 0.02 --lift 0.06 --strength-mod 0.08 --n 3
   ```
   破れ (最大到達位置) と分離 (中点の和) の両方を判定して出す。NG なら
   strength / orbit / scale を動かして再計算する。数値の根拠は HTML のコメントに残す
   (後で「なぜ 0.27 なのか」を再発見しなくて済む)。
2. 描いて確かめるときは、**スクリーンショットだけで判断しない**。rAF のループが
   走っている間はコンソールから `draw(t)` を呼んでも次フレームで上書きされ、
   「融合した瞬間」を狙って撮れない。代わりに `mc.field` を直接読む
   (`references/field-probe.md` の snippet)。分離期の中点の値が isolation を
   下回っているか、融合期の中心が十分大きいかを数字で見る。
3. それでも絵で見たいなら、ページ側に固定タイムステップのモード
   (`?record=1` や `?t=5.7` でその時刻だけ描く) を付ける。sqm/web/slshader の
   metaball_duo.html が手本。

## よくある見落とし

- 「3 つに分かれた」ように見えて、実は 1 球が壁で切れて 2 つに見えているだけ、
  がある。field を読めば中心付近の値で区別できる。
- `MarchingCubes` は 1 メッシュ 1 材質。材質ごとに塊を分けたいなら場を複数作って
  並べる。場が複数あっても予算は場ごとに同じ。
- `isolation` を下げると球が太る (r_iso が伸びる) ので、予算を取り直す。
- 解像度 (`resolution`) を上げても破れは直らない。境界の問題であって精度の問題ではない。
